# DAWA — P0-A: Real Uplift Phone Call Integration Spike

You are implementing the first gated technical spike for **DAWA**, an Urdu-first medication companion for low-literacy patients.

This is NOT a request to build the full product.

The sole purpose of this phase is to prove that a minimal FastAPI backend running on Replit can create/configure an Uplift realtime assistant and use Uplift's official outbound calling API to place a **real Urdu AI phone call to a Pakistani phone number**.

## Authoritative source

The project includes the official:

**“Uplift AI — Voice AI Hackathon Guide”**

Treat that guide as the source of truth for all Uplift API behavior in this phase.

Do not invent endpoints, request fields, models, regions, or error semantics that conflict with the guide.

Important facts from the guide that must be respected:

* Pakistani outbound calling works ONLY through the Singapore region.
* Base URL:
  `https://ap-southeast-1.api.upliftai.org/v1`
* Assistant creation:
  `POST /realtime-assistants`
* Outbound call:
  `POST /calls`
* Call/session status:
  `GET /realtime-assistants/{assistantId}/sessions`
* Calls may target Pakistani numbers only.
* `dispatched` does NOT mean answered.
* Uplift has a one-concurrent-outbound-call-per-organization limit.
* Poll call status politely, approximately every 2–5 seconds.
* Uplift API credentials must remain server-side.
* Use an `Idempotency-Key` for outbound call safety.

# STEP 6 — ERROR HANDLING

Handle the documented Uplift cases deliberately.

At minimum distinguish:

* 400 invalid request / number
* 401 invalid API key
* 402 insufficient credits
* 404 assistant not found
* 409 number busy
* 409 duplicate in flight
* 429 concurrent outbound call limit
* 429 platform line capacity
* 429 API throttling
* 500 Uplift infrastructure error

Do not expose raw secret-bearing request headers.

Return useful sanitized FastAPI responses.

When possible preserve Uplift's useful error message.

Do not implement complicated retry loops yet.

For this spike, clear error reporting is more important than automated retries.
