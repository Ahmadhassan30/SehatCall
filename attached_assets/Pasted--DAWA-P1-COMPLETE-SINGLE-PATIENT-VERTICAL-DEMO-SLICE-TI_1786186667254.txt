========================================================
PRODUCT
========================================================

DAWA is an Urdu-first medication companion for low-literacy patients.

Core product statement:

"Every prescription assumes you can read. DAWA doesn't."

The PATIENT does not use the app.

The patient receives a normal Pakistani phone call from Uplift AI.

The mobile application already present in this repository is a CAREGIVER
dashboard only.

Target demo patient:

Razia Bibi

DAWA must demonstrate:

1. verified medication information;
2. low-literacy medication recognition;
3. deterministic medication resolution;
4. ambiguity rather than guessing;
5. proactive real Urdu phone calling;
6. safety around uncertain/different medication instructions;
7. caregiver visibility.

========================================================
DETERMINISTIC VMR
========================================================

Implement:

backend/app/services/vmr.py

VMR = Verified Medication Resolution.

The LLM must NOT determine whether a medicine is verified.

VMR takes observed patient cues and compares them ONLY to caregiver-verified
medication cues.

Return exactly one of:

UNIQUE
AMBIGUOUS
NO_MATCH


Suggested response:

{
  "status": "AMBIGUOUS",
  "candidateMedicationIds": [
    "metformin-500",
    "amlodipine-5"
  ],
  "bestDiscriminator": "stripe_color"
}

Example:

input:

{
  "package_color": "white"
}

must return:

AMBIGUOUS

because both medicine boxes are white.

It should identify:

stripe_color

as the best discriminator.


Input:

{
  "package_color": "white",
  "stripe_color": "blue"
}

must return:

UNIQUE
metformin-500


Input:

{
  "package_color": "white",
  "stripe_color": "red"
}

must return:

UNIQUE
amlodipine-5


Unknown/unverified cues must NEVER cause the resolver to invent an identity.

No fake confidence percentages.

No embeddings.

No fuzzy semantic drug matching.

No LLM calls.

VMR is deterministic Python.

Metformin medicine.

SAFETY RULES — NON NEGOTIABLE
========================================================

It may communicate only stored verified instructions.

"I only have one tablet in the verified instructions.
